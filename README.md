# GoGYM Landing Page

Repositorio independiente y desacoplado para la **Landing Page promocional de GoGYM** y su asistente inteligente para administradores de gimnasios, **GYMY AI**.

---

## 🚀 Características

- **Diseño Oficial GoGYM:** Respeta estrictamente la paleta y estética del ecosistema (fondo negro `#000000`, acentos gris oscuro `#1f2937` y gradiente rojo/naranja `#ff3131` / `#ff914d`).
- **Showcase de GYMY AI:** Demostración interactiva de las capacidades del asistente virtual (predicción de vencimientos, optimización de aforo, resumen de check-ins y reemplazo de profesores).
- **Control de Acceso QR:** Sección destacada sobre el ingreso ágil con lector de cámara web y credenciales digitales.
- **Planes y Precios Transparentes:** Detalle de suscripciones para boxes, gimnasios individuales y cadenas.
- **Formulario de Captura de Clientes:** Lead generation directo para solicitud de demostración y onboarding.

---

## 🛠️ Tecnologías

- **Framework:** Next.js 16 (App Router)
- **UI:** React 19
- **Estilos:** Tailwind CSS 4 + PostCSS
- **Iconografía:** Heroicons & React Icons

---
